MongoDB Atlas Connection String Guide

To connect your MongoDB Atlas cluster, create a .env file in your project root or set the environment variable on Render:

# Environment Configuration (.env)
PORT=3000
NODE_ENV=production

# MongoDB Atlas URI (Replace <username> and <password> with your MongoDB Atlas database user):
MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/queue_db?retryWrites=true&w=majority

# Docker Deployment Command:
docker build -t queue-system:latest .
docker run -p 3000:3000 -e PORT=3000 queue-system:latest
